02 · Proposed Solution
SIH 2026 · SIH26155

Turn any device config into a pass/fail with the fix attached

The real problem
Attackers rarely need a zero-day. Telnet left on, a weak cipher, an open mgmt port — a single mis-set line is the way in.
Why it stays broken
Auditing means an expert reading configs by hand, or a tool locked to one vendor that breaks the day a new device arrives.
Our answer
One vendor-agnostic, offline auditor. Upload a config, get a compliance verdict with copy-paste remediation.
How it works, in one breath
  • Reads a config from any firewall, router or switch and normalises it to one common security model.
  • Checks that model against CIS Benchmarks, NIST 800-53 and DISA STIGs the user selects.
  • Returns a per-device report: pass / fail, severity, and the exact CLI commands to harden it.
Innovation · what no one else builds

It learns a vendor it has never seen

Hard-coded parsers break on every new firmware. Ours falls back to a local, offline language model; when it is unsure, a Teach-a-Vendor screen shows the raw lines, an admin tags two of them, and the mapping is saved for good. No re-coding, no cloud, no waiting on a patch.

04 · Feasibility & Viability
SIH 2026 · SIH26155

Buildable now, because the hard 20% is the only part the model touches

Why it is feasible
  • 80% is a solved problem. Mature libraries already parse mainstream vendors, so the model only handles the unfamiliar long tail.
  • Rules are data, not code. CIS/NIST/STIG checks live in editable YAML, so coverage grows without touching the engine.
  • Runs on a laptop. A 7B local model is enough for line-level parsing; no GPU cluster, no cloud bill.
Grand-finale MVP: 2 known vendors + 20 high-value CIS checks + one vendor taught live on stage. Small enough to finish, sharp enough to win the room.
Risks, and how we beat them

Model mis-reads a config line

Deterministic parser runs first; the model is validated against the schema, and low-confidence output is quarantined into the Teach screen rather than trusted blindly.

"AI that invents a fix" is dangerous

Remediation is drawn from vendor-verified command templates, not free-form generation. Every fix is traceable to a benchmark rule.

Scope creep across 30 vendors

The whole point is that we don't pre-build them. New vendors are taught, so breadth is a feature, not a backlog.
